Update javeabliss.com to add a discreet, elegant “FOR SALE” tab in the main navigation.

The purpose is NOT to publicly advertise the apartment details or price on the website.

The FOR SALE page should simply act as a premium registration gateway for potential buyers and real-estate agencies who want access to the private sales brochure.

IMPORTANT:
- DO NOT show the asking price anywhere on the public FOR SALE page.
- DO NOT show detailed financial information.
- DO NOT show rental revenues.
- DO NOT reproduce the full sales brochure on the website.
- DO NOT mention Airbnb.
- Keep the page elegant, discreet and exclusive.
- The detailed property information should only become available inside the PDF after successful email verification.
- Keep the existing Javea Bliss design, fonts, colors and overall visual identity.
- Use only existing real photographs from JaveaBliss.com. Never use AI-generated property images.

7. VERIFICATION SECURITY
==================================================

Handle verification server-side.

Requirements:

- random 6-digit code
- expires after 10 minutes
- maximum 5 incorrect attempts
- resend available after 60 seconds
- generating a new code invalidates the previous code
- rate-limit by IP and email
- do not put codes in URLs
- do not store codes in localStorage
- store a hash of the verification code instead of plain text where practical

After successful verification:

verification_status = verified
verified_at = timestamp

==================================================
11. PROTECT THE PDF FILES
==================================================

VERY IMPORTANT:

Do NOT place the brochures in a publicly accessible /public directory with predictable URLs.

Someone should NOT be able to type:

javeabliss.com/brochure.pdf

and bypass registration.

Store the brochure files in protected server-side storage.

Serve them through an authenticated endpoint such as:

GET /api/sales-brochure?lang=en

Before returning a brochure:

1. Confirm the session is verified.
2. Confirm verification is still valid.
3. Return the correct language PDF.

Unverified requests must receive 401/403.

Do not include email addresses, names or other personal information in the PDF URL.
